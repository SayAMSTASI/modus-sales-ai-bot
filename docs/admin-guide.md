# Инструкция администратора Modus Sales AI Bot

## Роль администратора

Администратор управляет пилотом через личный чат с тем же Telegram-ботом. Отдельной
веб-панели в MVP нет.

Администратор может:

- подтверждать, отклонять, блокировать и восстанавливать пользователей;
- просматривать список пользователей, их активность и последние вопросы;
- назначать и снимать права дополнительных администраторов;
- смотреть общую активность, расход и удовлетворённость;
- просматривать, изменять и откатывать общий набор skills;
- проверять корпоративную авторизацию и каталог MCP tools.

Все пользователи пилота используют один общий набор skills и один общий read-only
allowlist MCP tools. Индивидуальные наборы инструментов и лимиты не настраиваются.

## Типы администраторов

В системе есть два типа администраторов:

- базовые — перечислены в защищённой переменной `ADMIN_TELEGRAM_IDS`;
- назначенные — выбраны из активных пользователей непосредственно в Telegram.

Базового администратора нельзя заблокировать или лишить прав через Telegram. Это
аварийный контур управления. Назначенного администратора можно вернуть к роли
обычного пользователя без перезапуска бота.

## Вход в панель управления

1. Откройте личный чат с ботом и нажмите «Запустить».
2. Нажмите «⚙️ Управление».
3. Выберите нужный раздел:
   - «👤 Пользователи»;
   - «👥 Администраторы»;
   - «📊 Активность»;
   - «⭐ Удовлетворённость»;
   - «🛠 Навыки»;
   - «🔎 MCP».

Эти разделы также доступны отдельными кнопками постоянного меню администратора.

## Подтверждение нового пользователя

Когда неизвестный пользователь нажимает «Запустить»:

1. OpenAI и MCP для него не вызываются.
2. Все действующие администраторы получают уведомление с Telegram ID и username.
3. Нажмите «Разрешить» или «Отклонить».
4. Пользователь автоматически получит результат решения.

При разрешении пользователь становится активным и получает общий набор MCP tools.
При отклонении доступ закрывается.

## Список пользователей и карточка

Откройте «👤 Пользователи». На экране отображаются количества:

- 🟢 активных;
- 🟡 ожидающих решения;
- 🔴 заблокированных.

Используйте кнопки «Все», «Активные», «Ожидают» и «Блок» для фильтрации. Если
пользователей больше размера страницы, используйте «Назад» и «Далее».

Карточка пользователя содержит:

- Telegram ID и username;
- статус и роль;
- последнюю активность;
- число сохранённых вопросов;
- число успешных OpenAI-запросов;
- входные и выходные токены;
- расчётную стоимость;
- среднюю оценку диалогов и число оценок.

Из карточки можно:

- открыть последние 10 вопросов;
- заблокировать или восстановить доступ;
- назначить активного пользователя администратором;
- снять права назначенного администратора.

## Просмотр вопросов и приватность

Кнопка «📝 Последние вопросы» показывает для каждого вопроса время, результат
обработки и текст. Длинный вопрос сокращается в интерфейсе до 500 символов.

По умолчанию журнал хранит текст вопросов 30 дней. Ответы агента в него не
копируются. OAuth-токены, API keys, Telegram token и другие секреты не должны
появляться в интерфейсе или логах.

Администратор должен использовать журнал только для сопровождения пилота и не
пересылать пользовательские вопросы за пределы согласованного контура.

## Блокировка и восстановление доступа

Чтобы заблокировать пользователя:

1. Откройте «👤 Пользователи».
2. Выберите пользователя.
3. Нажмите «⛔ Заблокировать».

Блокировка действует без перезапуска. Система удаляет текущий контекст, ожидающую
оценку и сохранённые OAuth-сессии пользователя. Историческая статистика и журнал
вопросов сохраняются до штатного срока очистки.

Чтобы вернуть доступ, откройте карточку заблокированного пользователя и нажмите
«✅ Разблокировать». Для работы с MCP пользователю потребуется снова войти через
Keycloak.

## Управление администраторами

Чтобы назначить администратора:

1. Откройте «👥 Администраторы».
2. Нажмите «➕ Добавить администратора».
3. Выберите пользователя из списка активных пользователей.
4. Проверьте username и Telegram ID.
5. Нажмите «✅ Назначить».

Неизвестного, ожидающего или заблокированного пользователя назначить нельзя.

Чтобы снять права:

1. Нажмите «➖ Снять права администратора».
2. Выберите назначенного администратора.
3. Подтвердите снятие прав.

Пользовательский доступ при этом сохраняется. Базовые администраторы в список
снятия прав не включаются. Назначения и снятия прав записываются в audit БД.

## Управление skills

Изменение skill влияет на всех пользователей пилота и применяется к следующему
запросу без перезапуска.

`sales-core` отмечен в списке как «⭐ Главная роль». Он задаёт роль агента,
маршрутизацию запроса и выбор остальных skills. Остальные skills являются рабочими
модулями. Системный read-only policy не редактируется через Telegram и всегда имеет
приоритет над текстом главной роли.

1. Откройте «🛠 Навыки».
2. Выберите skill.
3. Нажмите «👁 Посмотреть», чтобы проверить текущий текст и источник версии.
4. Нажмите «✏️ Изменить».
5. Отправьте полный новый текст skill одним сообщением.
6. Проверьте показанное изменение.
7. Нажмите «Применить» или «Отменить».

Каждая применённая редакция сохраняется в БД с номером версии и автором. Кнопка
«↩️ Откатить версию» возвращает предыдущую версию, а после исчерпания версий —
базовый текст из Git. Базовый файл в Git не удаляется.

Перед применением убедитесь, что текст не содержит паролей, токенов, персональных
данных, разрешения на write-операции или инструкций, противоречащих политике
пилота.

## MCP и корпоративная авторизация

Каждый пользователь обращается к Jira, Bitrix и KTalk со своим Keycloak token.
Права администратора бота не расширяют права корпоративной учётной записи.

Кнопка «🔎 MCP статус» показывает:

- активна ли авторизация текущего администратора;
- какие MCP-серверы настроены;
- какие tools разрешены allowlist.

Текущая конфигурация работает только на чтение. Включение write-tools через
Telegram не поддерживается и требует отдельного изменения конфигурации, проверки
безопасности и согласования.

Для технической сверки каталога администратор может использовать:

```text
/mcp_discover jira
/mcp_discover bitrix
/mcp_discover ktalk
```

Discovery только читает каталог tools, ничего не включает и не вызывает. Для него
нужна собственная действующая авторизация администратора.

## Активность и удовлетворённость

Раздел «📊 Активность» показывает:

- число активных пользователей;
- вопросы за 24 часа и 7 дней;
- успешные OpenAI-запросы за 7 дней;
- суммарные токены и расчётную стоимость за 7 дней;
- среднее время ответа.

Раздел «⭐ Удовлетворённость» показывает:

- общее число оценок;
- среднюю оценку по шкале 1–5;
- CSAT — долю оценок 4 и 5;
- среднюю оценку за последние 7 дней;
- распределение оценок от 1 до 5.

Оценка запрашивается перед началом нового диалога, если в предыдущем диалоге был
ответ агента.

## Действия при проблемах

- Пользователь не появляется — попросите его открыть личный чат и нажать
  «Запустить».
- MCP недоступен только одному пользователю — проверьте его вход через Keycloak и
  корпоративные права.
- MCP недоступен всем — проверьте «🔎 MCP статус» и передайте DevOps название
  сервера и время ошибки без токенов и пользовательских данных.
- Ошибка после изменения skill — откройте skill и выполните rollback.
- Нет административных кнопок — проверьте, что пользователь активен и входит в
  список администраторов.
- Базовый администратор изменился — обновите `ADMIN_TELEGRAM_IDS` через защищённую
  конфигурацию и перезапустите сервисы по инструкции DevOps.

Резервные команды администратора:

```text
/users
/activity
/satisfaction
/admins
/skills
/mcp_status
```

Основной интерфейс рассчитан на кнопки. Команды с ручным Telegram ID следует
использовать только для сопровождения и автоматических проверок.
