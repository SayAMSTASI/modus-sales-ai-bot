# Контекст продуктов Modus для разбора транскрипций

## Modus BI

Типовые темы в звонках и встречах:
- замещение Power BI и других BI-систем;
- дашборды, визуализации, отчёты для руководства;
- доступы, роли, RLS, просмотр по ссылке;
- импортозамещение;
- работа с SQL Server, ClickHouse, PostgreSQL, Excel, 1С;
- лицензирование пользователей;
- обучение аналитиков и администраторов;
- демо-доступ, пилот, очная встреча или ВКС.

## Modus ETL

Типовые темы:
- сбор данных из 1С, SQL-баз, файлов и веб-сервисов;
- подготовка витрин данных;
- трансформация, очистка, дедубликация;
- замещение Power Query;
- коннекторы к Bitrix24 и другим системам;
- интеграция с хранилищами данных.

## Power BI migration

Если клиент обсуждает Power BI, отдельно извлекать:
- что именно нужно заместить: визуализации, DAX, Power Query, Report Server, модель данных, доступы;
- требуется ли автоматическая конвертация;
- кто будет переносить дашборды: клиент, Modus, партнёр;
- нужны ли обучение и пилот;
- есть ли ограничения по лицензированию и числу пользователей.
