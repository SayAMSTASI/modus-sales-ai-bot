# Схема актуальной карточки сделки

```markdown
## Актуальная карточка сделки

Компания:
Контакт(ы):
Роли контактов:
Продуктовый интерес:
Текущий статус квалификации:
Краткая суть проекта:
Подтверждённые боли:
Критерии выбора:
Процесс принятия решения:
ЛПР / владелец бюджета:
Метрики проекта:
Договорной / закупочный процесс:
Чемпион:
Конкуренты / альтернативы:
Риски:
Следующий шаг:
Что нужно уточнить:
Что обновить в CRM:
Дата последнего обновления:
```

Если данных нет, писать `не выявлено`, а не придумывать.
