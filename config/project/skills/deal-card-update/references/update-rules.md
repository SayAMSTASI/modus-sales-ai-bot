# Правила обновления

## Приоритет источников

1. Прямые слова клиента в новой транскрипции.
2. Прямые слова менеджера о договорённостях.
3. Предыдущая актуальная карточка сделки.
4. Предположения менеджера.

## Смена статуса уверенности

- `гипотеза` → `подтверждено`, если клиент прямо подтвердил факт.
- `подтверждено` → `противоречие`, если новая информация ему противоречит.
- `частично подтверждено` сохранять, если новой информации недостаточно.

## Не считать изменением

- Клиент не упомянул старый факт в новой встрече.
- Менеджер повторил старую информацию без нового подтверждения клиента.
- В новой встрече обсуждали другую тему.
