# Временная схема полей до точного маппинга Bitrix

Пока точные поля Bitrix не переданы, использовать разделы:

- Контакт;
- Компания;
- Суть потребности;
- Продуктовый интерес;
- Боль клиента;
- Критерии выбора;
- Процесс решения;
- ЛПР / владелец бюджета;
- Конкуренты / альтернативы;
- Риски;
- Следующий шаг;
- Комментарий в таймлайн;
- Задача менеджеру.

Когда появятся реальные поля Bitrix, заменить эту схему на таблицу:
`техническое поле → название в интерфейсе → правила заполнения → можно обновлять через MCP`.
