# Будущий сценарий с MCP

1. Проверить, указана ли сделка или компания.
2. Если сделка не указана, использовать поиск сделки.
3. Получить текущую карточку сделки.
4. Сравнить текущие поля с новой карточкой сделки.
5. Сформировать список proposed changes.
6. Попросить подтверждение:
   `Подтвердите, что можно обновить эти поля в Bitrix24.`
7. После подтверждения обновить только разрешённые поля.
8. Создать задачу только если она конкретная: действие, владелец, срок.
9. Добавить комментарий в таймлайн в нейтральной формулировке.

Если есть сомнение, не писать в CRM, а вынести в блок `требует проверки`.
