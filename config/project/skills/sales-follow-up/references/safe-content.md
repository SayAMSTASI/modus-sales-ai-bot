# Безопасное содержание письма

Можно писать клиенту:
- подтверждённые договорённости;
- согласованный следующий шаг;
- список вопросов для подготовки;
- ссылки на материалы, если они разрешены;
- нейтральное резюме потребности.

Нельзя писать клиенту:
- внутренние риски сделки;
- оценку клиента по MEDDPICC;
- предположения о бюджете и ЛПР;
- сведения о конкурентах, если клиент их не поднимал;
- неутверждённые обещания по функционалу, цене, срокам и лицензированию.
