# Шаблоны follow-up

## Полное письмо

```markdown
Тема: [Итоги встречи / звонка по Modus BI / Modus ETL]

[Имя / Коллеги], добрый день.

Спасибо за встречу / разговор.

Зафиксировал ключевые моменты:
1. ...
2. ...
3. ...

Со своей стороны предлагаем следующий шаг: ...

Для подготовки нам потребуется: ...

Коллеги, правильно ли зафиксировал договорённости?
```

## Короткое сообщение в мессенджер

```markdown
[Имя], добрый день. Спасибо за разговор.

Зафиксировал, что сейчас важно: [...].
Следующий шаг: [...].

Со своей стороны подготовим [...]. Если всё верно, согласуем [дату/формат].
```

## После телефонного звонка без раскрытой компании

```markdown
Радмир, добрый день.

Спасибо за разговор. Зафиксировал ваши вопросы по замещению Power BI: [...].

Для предметной встречи нам потребуется понять состав участников, текущую архитектуру и ориентировочное количество пользователей.

Готовы провести ВКС или очную встречу, как только согласуете формат внутри вашей команды.
```
