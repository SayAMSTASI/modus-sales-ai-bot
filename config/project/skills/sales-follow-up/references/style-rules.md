# Стиль follow-up

Использовать:
- короткие абзацы;
- конкретные договорённости;
- нейтральный деловой тон;
- формулировки `зафиксировал`, `предлагаю следующим шагом`, `со своей стороны подготовим`;
- вопрос на подтверждение в конце.

Избегать:
- `уникальное решение`;
- `лучшее на рынке`;
- `революционная платформа`;
- давления: `ждём срочного ответа`, `надо срочно решить`;
- внутренней терминологии без необходимости.
