# MEDDPICC Modus

## Metrics / Метрики

Количественные показатели, которые важны заказчику в разрезе проекта: рост продаж, сокращение затрат, экономия человекочасов, снижение ошибок, повышение NPS, скорость подготовки отчётности, снижение трудоёмкости аналитики.

Если нет чисел, сроков или способа измерения, статус не выше `частично подтверждено`.

## Economic Buyer / ЛПР, владелец бюджета

Человек, который контролирует бюджет и принимает конечное решение о закупке. Может отличаться от формального подписанта договора.

Технический специалист, аналитик или инициатор не считается ЛПР без подтверждения.

## Decision Criteria / Критерии принятия решения

Критерии, по которым клиент выбирает решение: функциональность, стоимость, российский реестр, работа с 1С, производительность, RLS, миграция с Power BI, лицензирование, обучение, поддержка, сроки внедрения, партнёрская экспертиза.

## Decision Process / Процесс принятия решения

Этапы и участники выбора: кто смотрит демо, кто формирует шорт-лист, кто тестирует, кто согласует бюджет, кто утверждает закупку, кто принимает техническое решение.

## Paper Process / Договорной или закупочный процесс

Юридические и закупочные барьеры: тендер, договор, ИБ, закупочный комитет, NDA, проверка поставщика, согласование реестра ПО, закупочная процедура.

## Identify Pain / Боль клиента

Подтверждённая проблема, которую Modus может решить. Технический запрос сам по себе не всегда боль. Важно понять последствия: ручной труд, расхождение данных, невозможность управленческой аналитики, риск из-за Power BI, ограничения текущей системы.

## Champion / Чемпион

Внутренний сторонник, который заинтересован в успехе проекта, имеет влияние и готов продвигать решение внутри клиента. Активный контакт не равен чемпиону.

## Competition / Конкурентное окружение

Альтернативы: Power BI, текущая система, open source, самостоятельная разработка, российские BI-вендоры, интеграторское решение, ничего не менять.

## Правило SQL

SQL возможен только при подтверждении обязательных элементов:
- боль клиента и соответствие Modus;
- ЛПР;
- критерии принятия решения;
- процесс принятия решения.

Если хотя бы один из этих элементов не выявлен, указывать `MQL / квалификация не завершена`.
